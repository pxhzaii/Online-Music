# Online-Music

自建音乐库方案：**Cloudflare R2 存储音乐文件 + Vercel 无服务器接口 + 洛雪音乐自定义音源**，零成本运行。

本项目核心是部署在 Vercel 的接口程序 `api/music.js`（增强版），负责两件事：

1. 列出 R2 桶内的全部音乐文件
2. 生成播放链接（10 分钟签名链接，或永久公开直链）

## 功能特性

- **全量列表**：自动使用 `ContinuationToken` 分页拉取，曲库超过 1000 个文件也不会漏歌（原版单次接口最多返回 1000 个对象，超量会静默丢失）
- **双链接模式**：
  - **签名模式**（默认）：返回预签名链接，默认 10 分钟有效，可用 `R2_URL_EXPIRES` 自定义
  - **永久直链模式**：配置 `R2_PUBLIC_BASE_URL` 后返回不带签名的公开直链，永久有效，可写入 M3U 播放列表或分享给外部播放器长期使用
- **安全防护**：`file` 参数校验（拒绝路径注入）、统一的错误响应格式 `{ success, message }`
- **洛雪对接**：配套自定义音源脚本，支持歌名+歌手模糊匹配、多音质智能选择与降级、曲库直搜、双层缓存（列表缓存 10 分钟 / 链接缓存自动适配有效期）

## 快速开始

1. Fork 本仓库，在 Vercel 中导入（框架预设无需修改）
2. 配置环境变量（见下表，R2 密钥在 Cloudflare 控制台「R2 → Manage R2 API Tokens」创建，勾选 Object Read 并限定到目标桶）
3. 部署后用浏览器访问 `https://你的域名/api/music`，返回 `{"success":true,"files":[...]}` 即成功
4. 如需洛雪播放，按下方「洛雪音乐对接」一节配置音源脚本

## 环境变量

| 变量名 | 必填 | 说明 |
|---|:---:|---|
| `R2_ACCOUNT_ID` | ✅ | Cloudflare 账户 ID（R2 概览页可见） |
| `R2_ACCESS_KEY_ID` | ✅ | R2 API Token 的 Access Key |
| `R2_SECRET_ACCESS_KEY` | ✅ | R2 API Token 的 Secret Key |
| `R2_BUCKET_NAME` | ✅ | 音乐文件所在的桶名 |
| `R2_PUBLIC_BASE_URL` | ❌ | 公开直链基地址。设置后 `action=get` 返回**永久直链**；不设置则保持签名模式。形如 `https://pub-xxxxx.r2.dev` 或自定义域名 `https://music.example.com` |
| `R2_URL_EXPIRES` | ❌ | 仅签名模式生效：链接有效期（秒），默认 600，下限 60 |
| `R2_CUSTOM_DOMAIN` | ❌ | 仅签名模式生效：签名链接域名替换为自定义域名 |

## API 接口

### 列出全部文件

```
GET /api/music
GET /api/music?action=fetch     （两者等价）
```

响应：

```json
{
  "success": true,
  "files": ["晴天 - 周杰伦.flac", "华语/王力宏/大城小爱.mp3", "..."]
}
```

### 获取播放链接

```
GET /api/music?action=get&file=<文件key，URL编码>
```

响应：

```json
{ "success": true, "url": "https://...", "expires": 0 }
```

- `expires: 0` 表示永久直链（公开直链模式）
- `expires: 600` 表示签名链接剩余有效期（秒）

## 开启永久直链模式

1. Cloudflare 控制台 → R2 → 你的桶 → Settings → **Public access** 启用，得到 `https://pub-xxxxxxxx.r2.dev` 域名（推荐改绑自己的域名）
2. Vercel 环境变量添加 `R2_PUBLIC_BASE_URL` = 上一步域名，重新部署
3. 完成。链接永久有效，可直接拼接直链使用：`https://你的域名/文件名`（中文与空格需 URL 编码）

> **知情权衡**：公开访问放弃了签名防盗链。R2 公开访问不允许列出文件，他人只能按已知文件名访问，无法批量扫库；删除 `R2_PUBLIC_BASE_URL` 可随时切回签名模式，两种模式共存互不影响。

## 洛雪音乐对接

1. 将配套音源脚本 `R2音乐库-洛雪音源.js` 顶部的 `API_BASE` 改为你的接口地址（以 `/api/music` 结尾）
2. 洛雪音乐 → 设置 → 音源管理 → 导入该脚本，按需启用 wy / tx / kg / mg / kw 平台
3. 在任意平台歌单点播时，脚本按 **歌名 + 歌手** 自动匹配 R2 曲库；在酷我（kw）平台的"自定义源"入口可直接搜索曲库

**文件命名建议**（决定匹配成功率，推荐 `歌名 - 歌手.扩展名`）：

| 支持的命名 | 示例 |
|---|---|
| 歌名 - 歌手（推荐） | `晴天 - 周杰伦.flac` |
| 歌手 - 歌名 / 仅歌名 | `周杰伦 - 晴天.flac` / `晴天.flac` |
| 带目录层级 | `华语/王力宏/大城小爱.mp3` |
| 音轨号前缀 | `01-搁浅.mp3` |
| feat / 多歌手 | `千里之外 (feat. 费玉清).flac` |
| 同名多音质并存 | `晴天.mp3` + `晴天.flac`（按所选音质自动选文件） |

音质规则：请求 128k / 320k 优先 `mp3`、`m4a`；请求 flac / flac24bit 优先 `flac`、`wav`；首选格式不存在时自动降级到库内现有文件，不会播放失败。非音频文件（封面、歌词）自动忽略。

## 安全须知

- **接口地址保密**：部署完成后删除 Vercel 自动分配的默认域名，改用自己的域名；检查 GitHub 仓库页面是否残留 Vercel 徽标域名，一并删除。接口一旦公开，任何人都能列出并下载你的全部文件
- R2 密钥只保存在 Vercel 环境变量，不要写进代码或提交到仓库
- 如怀疑密钥/接口泄露：重新生成 R2 Token、更换域名并重新部署即可，不影响已上传文件
